# Block 1: Combinational Logic

In this block you'll learn the foundation of all digital design: **combinational logic**.

A combinational circuit is one where the output depends only on the current inputs — no memory, no clock, no state. Just pure logic operating on ones and zeros.

---

## What you'll learn

- How logic gates work and how to express them in TL-Verilog
- How to combine gates into useful circuits
- How multiplexers work and why they're everywhere
- How to read waveforms and match circuit behavior to code
