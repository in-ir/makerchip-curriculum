# Digital Design with Makerchip & TL-Verilog

> Learn digital design the way it should be taught: interactive, visual, and actually fun.

Built with [Makerchip](https://makerchip.com) and TL-Verilog as part of **Google Summer of Code 2026** with [Redwood EDA](https://www.redwoodeda.com/).

**Live site:** [in-ir.github.io/makerchip-curriculum](https://in-ir.github.io/makerchip-curriculum)

## What this is

This curriculum takes you from zero to designing real circuits in hardware, starting with logic gates and building toward a full processor. Every lesson has interactive Makerchip circuits embedded directly in the page. You write code, compile, and see your circuit running without ever leaving the browser.

No installation. No prior hardware experience. Just a browser.

## What you will learn

| Block | Topic |
|-------|-------|
| 1 | Combinational Logic |
| 2 | Sequential Logic |
| 3 | Memory & Arrays |
| 4 | Multi-FSM & Hierarchy |

## Run it locally

```bash
pip install mkdocs mkdocs-material
mkdocs serve
```

Then open `http://localhost:8000`.
